Connect API — Team Testing Guide

The agnostic integration hub between wholesale suppliers (SanMar, S&S, 4Over, 994+ PromoStandards) and any consumer platform. Nine endpoints — five live today, four on the agreed roadmap. Here's how to authenticate and test them in Postman.

Collection GraphX Connect API base_url http://localhost:8000 Auth header X-Orchestrator-Key
01

Authenticate

two mechanisms

Connect uses different auth for machines vs. people. Most endpoints are machine-facing and take a header key; the admin Login uses a session cookie. Know which one you're hitting.

machine / consumer — most endpoints

X-Orchestrator-Key header

Every request sends X-Orchestrator-Key: {{orch_key}}, validated against the integration_keys table. No key (or a bad one) → 401. This is already wired on every request in the collection.

admin / interactive — Login only

auth_token session cookie

Run POST /api/auth/login with your email + password. On 200 it sets an auth_token cookie that Postman re-sends automatically on later requests.

02

One-time setup

per teammate
  1. Open the collection → Variables tab.
  2. Set base_url → http://localhost:8000 if you run the backend locally, or the shared/deployed host.
  3. Set orch_key → your integration key. It's blank by default — without it the machine endpoints return 401. Ask the admin (or Sinchana) for a key.
If base_url points at localhost, the backend must be running: docker compose up -d postgres then uvicorn main:app --port 8000. Against a deployed host, skip this.
03

Run a test

smoke check → full run
  1. Hit a live endpoint first — Supplier Directory → List suppliers. Expect 200 with a JSON list. A 401 means your orch_key is wrong or missing.
  2. (Optional) Run Login with email + password to unlock the cookie-based admin routes.
  3. Use the Runner to fire the whole collection. The built-in tests pass live = 200 and planned = 404 (those aren't built yet, so 404 is the expected, correct result).

05

Response codes

uniform error envelope

Non-2xx responses share one shape: { "error", "detail", "request_id" }. List endpoints page with page + page_size and return { rows, total, page, page_size }.

401Missing / invalid X-Orchestrator-Key
403Key lacks the required scope
404Unknown resource (or a planned endpoint)
422Payload failed validation
429Rate-limited — see Retry-After
502/504Supplier upstream error / timeout
