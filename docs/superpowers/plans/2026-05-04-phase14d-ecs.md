# Phase 14d — ECS Fargate Infrastructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy API-HUB to AWS ECS Fargate end-to-end. Single CFN stack provisions backend + frontend + n8n services, RDS Postgres, EFS for n8n state, Secrets Manager, ALB, Cloud Map service discovery, IAM least-privilege roles. CI auto-deploys on merge to main.

**Architecture:** Three ECS Fargate services in one cluster. ALB terminates HTTPS at three subdomains (`api.`, `app.`, `n8n.`). Inter-service traffic uses Cloud Map private DNS (`backend.api-hub.local:8000`, `n8n.api-hub.local:5678`). RDS in private subnets, EFS for n8n persistent state, all secrets in Secrets Manager and injected via task definitions. GitHub Actions builds three images per merge to main and updates the stack.

**Tech Stack:** AWS CloudFormation, ECS Fargate, RDS Postgres 16, EFS, ALB, ACM, Route 53, Cloud Map, Secrets Manager, ECR, GitHub Actions, OIDC role for CI auth (no long-lived AWS keys).

**Tracking issue:** [#88](https://github.com/VisualGraphxLLC/API-HUB/issues/88)

**Branch:** `dev/phase14d-ecs`

**Depends on:** Phases 14a, 14b, 14c all merged.

**Manual prerequisites (one-time, before merge):**
- Route 53 hosted zone for the chosen domain (e.g., `staging.example.com`)
- ACM cert in the same region as the stack (us-east-1 for App Runner / Fargate is fine; pick one and stick to it)
- VPC with at least 2 public subnets + 2 private subnets, NAT gateway for private egress
- AWS account ID + region recorded in `.github/secrets`

## Task 8: GitHub Actions deploy workflow

**Files:**
- Create: `.github/workflows/deploy.yml`

- [ ] **Step 1: Write the workflow**

```yaml
name: Deploy to ECS (staging)

on:
  push:
    branches: [main]

permissions:
  id-token: write   # for OIDC AWS auth
  contents: read

env:
  AWS_REGION: us-east-1
  STACK_NAME: api-hub-staging
  ECR_BACKEND: api-hub-backend
  ECR_FRONTEND: api-hub-frontend
  ECR_N8N: api-hub-n8n

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Configure AWS credentials (OIDC)
        uses: aws-actions/configure-aws-credentials@v4
        with:
          role-to-assume: ${{ secrets.AWS_OIDC_ROLE_ARN }}
          aws-region: ${{ env.AWS_REGION }}

      - name: Login to ECR
        uses: aws-actions/amazon-ecr-login@v2

      - name: Build + push backend
        run: |
          ACCOUNT=$(aws sts get-caller-identity --query Account --output text)
          SHA=${GITHUB_SHA::8}
          docker build -t $ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_BACKEND:$SHA ./backend
          docker push  $ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_BACKEND:$SHA
          echo "BACKEND_URI=$ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_BACKEND:$SHA" >> $GITHUB_ENV

      - name: Build + push frontend
        run: |
          ACCOUNT=$(aws sts get-caller-identity --query Account --output text)
          SHA=${GITHUB_SHA::8}
          docker build \
            --build-arg NEXT_PUBLIC_API_URL=https://api.staging.example.com \
            --build-arg NEXT_PUBLIC_N8N_URL=https://n8n.staging.example.com \
            -t $ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_FRONTEND:$SHA ./frontend
          docker push  $ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_FRONTEND:$SHA
          echo "FRONTEND_URI=$ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_FRONTEND:$SHA" >> $GITHUB_ENV

      - name: Build + push n8n
        run: |
          ACCOUNT=$(aws sts get-caller-identity --query Account --output text)
          SHA=${GITHUB_SHA::8}
          docker build -f n8n.Dockerfile -t $ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_N8N:$SHA .
          docker push  $ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_N8N:$SHA
          echo "N8N_URI=$ACCOUNT.dkr.ecr.$AWS_REGION.amazonaws.com/$ECR_N8N:$SHA" >> $GITHUB_ENV

      - name: Deploy CFN stack
        run: |
          aws cloudformation deploy \
            --template-file deployment/ecs/api-hub.yaml \
            --stack-name $STACK_NAME \
            --region $AWS_REGION \
            --capabilities CAPABILITY_IAM \
            --parameter-overrides $(jq -r 'map("\(.ParameterKey)=\(.ParameterValue)") | .[]' deployment/ecs/parameters/staging.json | tr '\n' ' ') \
              BackendImageUri=$BACKEND_URI \
              FrontendImageUri=$FRONTEND_URI \
              N8nImageUri=$N8N_URI \
            --no-fail-on-empty-changeset

      - name: Run Alembic migration
        run: |
          ACCOUNT=$(aws sts get-caller-identity --query Account --output text)
          # Inject real values into migrate-task.json and register a task definition
          jq \
            --arg image "$BACKEND_URI" \
            --arg exec "arn:aws:iam::$ACCOUNT:role/api-hub-staging-EcsTaskExecutionRole" \
            --arg taskrole "arn:aws:iam::$ACCOUNT:role/api-hub-staging-BackendTaskRole" \
            --arg secret "arn:aws:secretsmanager:$AWS_REGION:$ACCOUNT:secret:api-hub/staging/POSTGRES_URL" \
            '.containerDefinitions[0].image=$image
             | .containerDefinitions[0].secrets[0].valueFrom=$secret
             | .executionRoleArn=$exec
             | .taskRoleArn=$taskrole' \
            deployment/ecs/migrate-task.json > /tmp/migrate-task.json

          aws ecs register-task-definition \
            --cli-input-json file:///tmp/migrate-task.json \
            --region $AWS_REGION

          aws ecs run-task \
            --cluster api-hub-staging \
            --launch-type FARGATE \
            --task-definition api-hub-migrate \
            --network-configuration "awsvpcConfiguration={subnets=[$(jq -r '.[] | select(.ParameterKey==\"PrivateSubnetIds\") | .ParameterValue' deployment/ecs/parameters/staging.json)],securityGroups=[$(aws ec2 describe-security-groups --filters Name=group-name,Values=*TaskSg* --query 'SecurityGroups[0].GroupId' --output text)],assignPublicIp=DISABLED}" \
            --region $AWS_REGION
```

(The `--network-configuration` line is fragile — for production replace with a stored SG/subnet lookup or bash variable resolution.)

# Deployment — AWS ECS Fargate

API-HUB runs on AWS ECS Fargate. Three services in one cluster behind

1. **Route 53 hosted zone** for the chosen domain (e.g. `staging.example.com`)
2. **ACM certificate** in the deploy region covering `*.<domain>`
3. **VPC** with at least 2 public + 2 private subnets and a NAT gateway
4. **GitHub OIDC role** in IAM trusting `repo:VisualGraphxLLC/API-HUB:ref:refs/heads/main`
   with permissions: ECR push, CloudFormation deploy, ECS register/run-task,
